## 📌 Fast React Pizza

A modern pizza ordering application built with React.

This is a fully functional front-end application allows users to browse a menu, add pizzas to a cart, and place an order with optional priority delivery. It also includes geolocation support to automatically detect the user’s address.

---

## 🚀 Features

- Browse pizza menu
- Add/remove items from cart
- Update item quantity
- Create an order
- Optional priority delivery (+20%)
- Automatic address detection (geolocation)
- Manual address input with validation
- Order status page
- Loading states and error handling

---

## 🛠️ Tech Stack

- React
- React Router
- Redux Toolkit
- Tailwind CSS
- Vite

---

## 💡 What I learned

- Managing global state with Redux Toolkit
- Working with async logic (`createAsyncThunk`)
- Handling forms and validation
- Using React Router loaders and actions
- Building a real user flow (cart → order → status)
- Handling edge cases (errors, loading states)

---

## ⚠️ Notes

- Geolocation may not work in all environments (browser/device limitations)
- In such cases, users can manually enter their address

---

npm install
npm run dev

# 🇷🇺 Русская версия

## 📌 Fast React Pizza

Современное приложение для заказа пиццы, созданное на React.

Пользователь может просматривать меню, добавлять пиццу в корзину и оформлять заказ с возможностью приоритетной доставки. Также реализовано автоматическое определение адреса через геолокацию.

---

## 🚀 Возможности

- Просмотр меню
- Добавление/удаление пиццы из корзины
- Изменение количества
- Оформление заказа
- Приоритетная доставка (+20%)
- Автоопределение адреса (геолокация)
- Ручной ввод адреса с валидацией
- Страница статуса заказа
- Обработка загрузки и ошибок

---

## 🛠️ Технологии

- React
- React Router
- Redux Toolkit
- Tailwind CSS
- Vite

---

## 💡 Чему я научилась

- Управление состоянием через Redux Toolkit
- Работа с асинхронными запросами (`createAsyncThunk`)
- Работа с формами и валидацией
- Использование loader и action в React Router
- Построение полного пользовательского сценария
- Обработка ошибок и состояний загрузки

---

## ⚠️ Примечание

- Геолокация может работать не во всех браузерах/устройствах
- В этом случае пользователь может ввести адрес вручную
